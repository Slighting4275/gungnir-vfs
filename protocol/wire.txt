# The gungnird wire protocol (v2): the one table both sides are tested against.
#
# src/daemon-rust/src/proto.rs and src/client-zig/src/proto.zig each define these values;
# `cargo test` and `./zb test` both read this file and fail on any value that differs, any
# name one side lacks, or any name the file lacks. Change a value here, on both sides, and
# (for a layout change) bump `version`, all in one commit.
#
# Format: one entry per line, `<group> <name> <value>`; values are decimal, or hex with
# 0x. `frame` lines are whole encoded frames in hex. Blank lines and `#` comments are
# ignored.
